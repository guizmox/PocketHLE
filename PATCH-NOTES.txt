PocketHLE Host Battery v2 + Brightness
Base: f6475bf54fd043361984ac2b2320a87b4476ad4a. Replaces Host Battery v1.
Includes host battery queries (Windows/Android), CE subscriptions, SDK shell alerts,
and corrected four-position brightness. No game/SDK binaries included.

Battery:
- Windows GetSystemPowerStatus; Android sticky ACTION_BATTERY_CHANGED (no permission/receiver).
- Shared one-second cache, fUpdate forces refresh. Failed read returns unknown state.
- GetSystemPowerStatusEx/Ex2 retain CE ABI and validate output; successful reads preserve LastError.
- RequestPowerNotifications/StopPowerNotifications now maintain bounded process registrations.
- Filtered POWERSTATUSCHANGE/POWERINFOCHANGE records, pending retry when queue is full.
- Queue close/process teardown release registrations. No additional host worker/timer.
- ReadMsgQueue preserves records on invalid/small buffers, cooperatively waits and returns BOOL FALSE on timeout.
- SDK SysMessages LOWBATERY_MSG/CRITICALBATERY_MSG are delivered on entering low/critical.
  Correctly spelled BATTERY aliases are accepted too; one registered ID per severity.
  No repeated alerts until recovery/charging. Unknown readings do not rearm/create alerts.
  Payload is zero params; SDK sample acts on message IDs. No forced shutdown.
- Charger-fault notification is not synthesized: Windows battery API exposes no reliable charger fault.

Brightness:
- Four slider values 1/11/21/31 produce distinct ascending brightness.
- SECOND position (11) is the original unmodified image, before fake brightness existed.
- Empty, wrong-type, zero or out-of-range registry values fall back to 11.
- Default Level/OnLevel 11, DimLevel 0; valid saved choices retained.
- First: 50% darkening; third: 1/12 white blend; fourth: 1/6 white blend (previous reduced max).
- Presentation only; guest framebuffer bytes remain unchanged.
