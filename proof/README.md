# Game captures and reproduction evidence

These files describe recorded runs, supplied presentation images and targeted
probes from different revisions. They are not an installation guide, a current
compatibility certification or a guarantee of a full playthrough. Commands and
patch references inside a report belong to that report's revision; use the
current [build guide](../docs/BUILD.md) and [settings reference](../docs/OPTIONS.md)
for new runs. Do not use old fixture patches as production fixes.

Some older notes omit an exact commit, date or hardware identity. That omission
limits the claim; it is not filled in by the date of this index. Image-only
assets under `games` are presentation references unless a run report establishes
more. Original reports and paths are retained so existing reproductions and
links remain usable.
